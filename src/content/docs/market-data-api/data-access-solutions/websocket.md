## Overview

Our WebSocket API solution ensures efficient and reliable access to market data. It offers a flexible framework, reflecting our commitment to innovation and customer satisfaction, by providing a versatile method for accessing dxFeed market data using the WebSocket protocol.

## Protocol

The WebSocket API operates using our proprietary dxLink.WebSocket protocol. [Learn more](https://demo.dxfeed.com/market-data/dxlink-ws/debug/#/protocol)

## Debug console

Test the [dxLink.Websocket](https://demo.dxfeed.com/market-data/dxlink-ws/debug/) solution. It provides standard mechanisms for: establishing a connection, maintaining it, reporting errors, authorization, and providing data exchange channels for different models.

## Technology stack and API compatibility

Our WebSocket solution is supported by APIs in several programming languages to accommodate diverse development environments:

- [JS API](https://github.com/dxFeed/dxLink?tab=readme-ov-file)
- [Java API](https://github.com/devexperts/QD/tree/master/dxfeed-api)
- [.NET API](https://github.com/dxFeed/dxfeed-graal-net-api)
- [C++ API](https://github.com/dxFeed/dxfeed-graal-cxx-api)
- [Swift API](https://github.com/dxFeed/dxfeed-graal-swift-api)

These APIs are developed as wrappers around a dynamically linked library, produced by compiling Java code, ensuring that the core logic remains consistent and performance-optimized across languages.
