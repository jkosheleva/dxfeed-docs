## Overview

JavaScript (TypeScript) API is a pre-built solution based on WebSocket, providing a user-friendly interface for accessing market data. Designed for JavaScript developers, it simplifies WebSocket complexities and offers an easy integration path for web applications. With JS API via dxLink.Websocket protocol, you can seamlessly incorporate market data into your web applications.
