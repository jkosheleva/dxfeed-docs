## Exchange codes for US Equities and Options

On the US market, different exchanges may trade the same instruments. The cumulative feed of events from all exchanges we call **composite**. Individual events from each exchange we call **regional**. To distinguish regional events, each exchange has a corresponding code. The list of the codes you can find in the tables below. In Europe, there are no regional events: each financial instrument has a different ticker symbol at each European exchange.
