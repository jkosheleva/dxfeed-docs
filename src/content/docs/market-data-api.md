## Overview

The dxFeed API makes it easy to work with our market data service. It offers a comprehensive toolset for integrating financial data applications. Explore connectivity options, support for various programming languages and access solutions. For more details, explore the [Data access solutions](/market-data-api/data-access-solutions/#data-access-solutions) section.

You can leverage its capabilities to manage entities, implement data filtering, specify field types, and fine-tune data aggregation processes to optimize performance and resource utilization across mobile, desktop, and web platforms.

To assist you in integrating market data into your application, we provide comprehensive guides, including:

- [dxFeed Java API tutorial](/market-data-api/market-data-api-tutorials/dxfeed-java-api-tutorial/#dxfeed-java-api-tutorial): Step-by-step instructions for utilizing the dxFeed Java API to access market data
- [Android integration tutorial](/market-data-api/market-data-api-tutorials/android-integration-tutorial/#android-integration-tutorial): Detailed guide on integrating dxFeed market data services into Android applications
- [iOS integration tutorial](/market-data-api/market-data-api-tutorials/ios-integration-tutorial/#ios-integration-tutorial): Instructions for embedding dxFeed market data into iOS applications

Our programming language APIs include Java, C++, .NET, JavaScript, GO, and Swift, and are accompanied by such access solutions as WebSocket, REST, and FIX.

## Key benefits

- Seamless management of connections, including automatic recovery from connection failures
- Automatic handling of various transport protocols, such as TCP/QTP and WebSocket/JSON
- Performance optimizations like backpressure support and network optimization
- Advanced market analysis tools
- Option to set aggregation periods for event listeners to decrease call frequency and lessen UI load
- Capability to conflate events ensuring event listeners receive the most current data, particularly useful for TICKER and HISTORY contracts
