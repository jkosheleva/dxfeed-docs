dxFeed Retail Services Platform is a B2B2C solution that keeps an end-user within a partner's ecosystem without additional sign-up on the dxFeed portal and makes it possible for partners to create user accounts, grant access to market data, and manage subscriptions via developed API methods

The system is represented as two independent services:

1. dxFeed Retail Services responsible for subscription management, entitlement control, and reporting.
2. dxFeed endpoint providing data feeds.
