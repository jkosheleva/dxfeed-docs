## Overview

This page provides detailed information on the various API methods available for the [Retail Services platform](/dxfeed-retail-products/retail-services-platform/#retail-services-platform). Each section provides comprehensive descriptions, usage guidelines, and examples to help our partners effectively utilize the designed API.

The API methods are divided into the following sections:

- [Account-related methods](/dxfeed-retail-products/retail-services-platform/retail-services-platform-api/account-related-methods/): provide key functionalities on account management, such as account creation, retrieving account details by ID or email, resetting a password, and updating an email address.
- [Subscription-related methods](/dxfeed-retail-products/retail-services-platform/retail-services-platform-api/subscription-related-methods/): cover the processes involved in subscription management, including subscription activation, confirmation, and cancellation, and retrieving information on subscriptions.
- [Access token-related methods](/dxfeed-retail-products/retail-services-platform/retail-services-platform-api/access-token-related-methods/): provide means for secure user authentication through token generation based on credentials.
- [Profile-related methods](/dxfeed-retail-products/retail-services-platform/retail-services-platform-api/profile-related-methods/): make it possible for an end user to access their personal profile page.
- [Tracking-related methods](/dxfeed-retail-products/retail-services-platform/retail-services-platform-api/tracking-related-methods/): provide means on monitoring trial subscriptions for tracking and reporting purposes.
