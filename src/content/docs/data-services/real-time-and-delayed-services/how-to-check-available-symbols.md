To look up available symbols, take the following steps:

1. Check available symbols in [IPF](https://tools.dxfeed.com/ipf).
2. Check [Symbology Guide](/data-model/symbology-guide/#symbology-guide) to get acquainted with corresponding symbology.
3. Send a request.

If symbols are not found, please check:

- Request structure
- Subscription limits
- Availability of the symbols
- OPOL

If all of the above is correct, please submit a ticket to [Help Desk](https://portal.dxfeed.com).
