## Software check

- API Version - latest
- TLS Version 1.2
- JRE Version - Oracle JRE 8.0
- .NET Framework Version 4.6

## Connection check

- IP address is public and whitelisted
- Allow Access in Firewall
- Correct endpoint and DNS resolving

## Subscription check

- [IPF](https://tools.dxfeed.com/ipf) web service
- Symbol format
- Symbol OPOL

## Support check

- Account at the [Help Desk](https://portal.dxfeed.com)
- Personal manager name, last name, phone, and email
- API documentation
- API samples

## C/C# API minimum requirements

For Windows:

- C++ Runtime v14
- .Net 4.5

For Linux:

- Libc version 2.12
