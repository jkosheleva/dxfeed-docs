## How to add an IP address

Submit a ticket to the [Help Desk](https://portal.dxfeed.com) and specify:

- Request type is **Whitelist an IP Addresses**
- Required IP address
- Endpoint where IP address should be added

dxFeed team will add your IP to the requested endpoint.

## IP address specification

To specify IP addresses for which you request access, check that these addresses are:

- Public
- Whitelisted
- Static
- IPv4
- Not a subnetwork

## Subnetwork access

To permit access to the subnetwork, submit a ticket to the [Help Desk](https://portal.dxfeed.com) and specify:

1. Request type is **Whitelist an IP Addresses**.
2. Your subnetworks are with prefixes and in the decimal system format. Read more for [RIPE](https://www.ripe.net/about-us/press-centre/understanding-ip-addressing) network.

Check that IP addresses are:

- Public
- Whitelisted
- Static
- IPv4

| One address | 1.2.3.4/32 |
| Subnetwork mask of 256 addresses | 1.2.3.0/24 |
